🛍️ Interactive Product Showcase Modal

🔗 [LIVE DEMO]([https://github.com/shaheereminent/ProductModal/settings/pages](https://shaheereminent.github.io/ProductModal/))

A small JavaScript practice project built to strengthen my understanding of DOM manipulation, event listeners, functions, data-* attributes, and modal interactions.

🎯 Purpose

This project was created as a practice challenge.

The goal was to recreate the general behavior of a modal window project I had previously built, but with a different design and use case so that I could test whether I actually understood the JavaScript concepts rather than simply following a tutorial.

I am building the functionality on my own without following a tutorial.

🧠 What I Practiced

This project focuses mainly on JavaScript concepts such as:

DOM selection

querySelector / querySelectorAll

addEventListener

Click events

Keyboard events

data-* attributes

dataset

Functions

Conditional statements

Loops

Adding and removing CSS classes

Finding the currently open modal

Reusing functions for multiple elements

Closing a modal with the overlay

Closing a modal with the Escape key

🛠️ Technologies

HTML5

CSS3

JavaScript

🤖 AI Usage

The HTML and CSS were generated with the help of AI to provide the structure and visual design for this practice project.

The purpose of using AI for the HTML/CSS was to avoid spending my practice time designing the interface and instead focus on understanding and writing the JavaScript functionality myself.

The JavaScript/programming logic was written by me as a learning exercise.

I am intentionally using this project to test my own understanding rather than copying JavaScript from a tutorial.

✨ Features

Three different product cards

Individual product detail modals

Open the correct modal based on the selected product

Close button

Overlay click to close

Escape key to close

Reusable JavaScript functions

Responsive layout

📚 Learning Goal

The main goal of this project is not the design itself.

The goal is to answer:

Can I build the JavaScript functionality myself after learning the concepts?

This project is part of my practice toward becoming more comfortable with JavaScript and DOM manipulation.
